# ติวไฟไหม้ · TGAT2 สุ่มทำโจทย์เพิ่ม

เว็บสำหรับผู้ที่มีชีท สแกน QR ในชีทแล้วจะเข้าหัวข้อนั้นทันที

- `index.html` หน้าเว็บเดียวใช้ร่วมทั้ง 4 ส่วน
- `assets/` หน้าตาและการทำงานของเว็บ
- `data/p1.bin` ถึง `p4.bin` คลังโจทย์ที่เข้ารหัสแล้ว เปิดได้ด้วยกุญแจใน QR เท่านั้น
- `data/keys.json` ข้อมูลตรวจกุญแจ (ไม่ใช่ตัวกุญแจ)

ชีทแยกส่วนเปิดได้เฉพาะส่วนนั้น เล่มรวมเปิดได้ทั้ง 4 ส่วน
ห้ามอัปโหลดไฟล์ `keys-ห้ามอัปโหลด.json` ขึ้นที่นี่
