# คู่มือเว็บ "สุ่มทำโจทย์เพิ่ม" · ติวไฟไหม้

เว็บนี้เป็นไฟล์ล้วน ไม่มีเซิร์ฟเวอร์ ไม่มีฐานข้อมูล และไม่มีระบบสมาชิก ผู้เรียนสแกน QR ในชีทแล้วจะเข้าหัวข้อนั้นทันที เว็บจะจำข้อที่ผู้เรียนทำไปแล้วไว้ในเครื่องของผู้เรียนเอง

## ในโฟลเดอร์มีอะไรบ้าง

| ไฟล์ / โฟลเดอร์ | ใช้ทำอะไร |
|---|---|
| `index.html` | หน้าเว็บทั้งหมด |
| `data/bank.json` | คลังโจทย์ 448 ข้อแบบ JSON (เว็บใช้ไฟล์นี้ก่อน) |
| `data/bank.csv` | คลังโจทย์ชุดเดียวกันแบบตาราง (ใช้เมื่อไม่มี bank.json) |
| `figures/` | รูปประกอบโจทย์ 128 รูป (.svg) ใช้กับ bank.csv |
| `n1/` ถึง `n6/` | ลิงก์สั้นสำหรับ QR เช่น `/n1` จะพาไปหัวข้อ N1 |
| `404.html` | สำรองให้ลิงก์สั้น `/n1`–`/n6` ใช้ได้แม้ไม่มีโฟลเดอร์ n1–n6 |
| `vendor/` | ตัวอ่านไฟล์ CSV สำรอง ใช้เมื่อโหลดจากอินเทอร์เน็ตไม่ได้ |
| `tests/` | ไฟล์ทดสอบ CSV รุ่นเก่า (ไม่ต้องอัปโหลดก็ได้) |
| `.nojekyll` | ไฟล์ว่าง บอก GitHub ให้ส่งไฟล์ตามเดิม ไม่ต้องแปลง |

## 1. อัปโหลดขึ้น GitHub Pages

> **แบบง่ายที่สุด (ไม่ต้องอัปโหลดโฟลเดอร์):** อัปโหลดแค่ 3 ไฟล์ `index.html`, `404.html` และ `bank.json` ไว้ที่หน้าแรกของ repository เว็บใช้งานได้ครบ ลิงก์สั้น `/n1`–`/n6` ใช้ได้ผ่าน `404.html` ส่วนวิธีด้านล่างเป็นแบบเต็มที่มีโฟลเดอร์

1. สมัครหรือเข้าสู่ระบบที่ github.com
2. กดปุ่ม **+** มุมขวาบน แล้วเลือก **New repository**
   - ตั้งชื่อ เช่น `tiwfaimai`
   - เลือก **Public**
   - กด **Create repository**
3. ในหน้า repository ที่สร้างใหม่ กดลิงก์ **uploading an existing file**
4. แตกไฟล์ ZIP ในเครื่องก่อน แล้วลาก **ทุกอย่างที่อยู่ข้างในโฟลเดอร์** มาวางในหน้าเว็บ ได้แก่ `index.html`, `data`, `figures`, `n1`–`n6`, `vendor` และ `.nojekyll`
   - Chrome และ Edge ลากทั้งโฟลเดอร์ได้
   - ถ้าไฟล์ `.nojekyll` ไม่ขึ้น (เครื่อง Mac ซ่อนไฟล์ที่ขึ้นต้นด้วยจุด) ข้ามไปได้ เว็บยังใช้งานได้ตามปกติ
5. เลื่อนลงล่าง กด **Commit changes**
6. ไปที่แท็บ **Settings** แล้วเลือก **Pages** ที่เมนูซ้าย
   - ช่อง Source เลือก **Deploy from a branch**
   - ช่อง Branch เลือก **main** และ **/ (root)**
   - กด **Save**
7. รอ 1–2 นาที แล้วรีเฟรชหน้า Pages จะเห็นที่อยู่เว็บ เช่น `https://ชื่อผู้ใช้.github.io/tiwfaimai/`
8. ทดสอบโดยเปิด `https://ชื่อผู้ใช้.github.io/tiwfaimai/n1` ต้องเข้าหน้าหัวข้ออนุกรมทันที

> **ลองดูในเครื่องก่อนอัปโหลด:** แตกไฟล์ ZIP ก่อน (เปิดจากในไฟล์ ZIP ตรง ๆ ไม่ได้) แล้วดับเบิลคลิก `index.html` จากนั้นกดปุ่ม "เลือกไฟล์คลังโจทย์" แล้วเลือก `data/bank.json` เบราว์เซอร์ไม่ยอมให้หน้าเว็บที่เปิดจากเครื่องอ่านไฟล์เอง จึงต้องเลือกให้ ขั้นนี้ไม่ต้องทำเมื่ออยู่บน GitHub Pages

## 2. เพิ่มหรือแทนที่โจทย์

แก้แค่ไฟล์ใน `data/` และ `figures/` ไม่ต้องแตะ `index.html`

**กฎข้อเดียวที่ต้องจำ: ถ้ามี `data/bank.json` เว็บจะใช้ไฟล์นี้ ถ้าไม่มีจึงใช้ `data/bank.csv`**

### แบบที่ 1: ใช้ไฟล์ JSON

เหมาะเมื่อได้ไฟล์โจทย์เป็นชุดจากเครื่องมือหรือ AI แบบเดียวกับคลังโจทย์ชุดนี้

1. ใน GitHub เปิดโฟลเดอร์ `data` แล้วกด **Add file** → **Upload files**
2. อัปโหลดไฟล์ใหม่ชื่อ `bank.json` ไฟล์เดิมจะถูกแทนที่
3. กด **Commit changes**

รูปที่ฝังมาในไฟล์ (`image_svg`) แสดงได้ทันที ไม่ต้องอัปโหลดรูปแยก

### แบบที่ 2: ใช้ตาราง CSV (แก้ใน Google Sheets หรือ Excel)

เหมาะเมื่ออยากพิมพ์หรือแก้โจทย์เองทีละข้อ

1. **ลบ `data/bank.json` ออกก่อน** (เปิดไฟล์ใน GitHub → ไอคอน ⋯ → **Delete file**) ถ้าไม่ลบ เว็บจะใช้ JSON ต่อ
2. แก้ตารางให้มีหัวคอลัมน์ตามตารางด้านล่าง แล้วบันทึกเป็น CSV
   - Google Sheets: **ไฟล์ → ดาวน์โหลด → CSV**
   - Excel: **บันทึกเป็น → CSV UTF-8 (Comma delimited)**
   - ต้องเป็น UTF-8 ภาษาไทยจึงไม่เพี้ยน
3. ตั้งชื่อไฟล์เป็น `bank.csv` แล้วอัปโหลดไปไว้ในโฟลเดอร์ `data`
4. อัปโหลดรูปใหม่ (ถ้ามี) ไว้ในโฟลเดอร์ `figures` ชื่อไฟล์ต้องตรงกับช่อง "ไฟล์รูป"

| คอลัมน์ | ใส่อะไร | ตัวอย่าง |
|---|---|---|
| id | รหัสข้อ ห้ามซ้ำ | QR-N1A-0001 |
| รหัสหัวข้อ | N1–N6 | N1 |
| ประเภทโจทย์ | ชื่อประเภท (ไม่ใส่ก็ได้) | อนุกรมเรขาคณิต |
| ดาว | 1, 2 หรือ 3 | 2 |
| ระดับ | ง่าย / กลาง / ยาก (ใช้แทนดาวได้) | กลาง |
| โจทย์ | ข้อความคำถาม | ข้อใดเป็นจำนวนถัดไปของอนุกรมนี้ |
| ข้อมูลประกอบ | ตัวเลขอนุกรม หรือข้อมูล (1)(2) ของ N5 ขึ้นบรรทัดใหม่ในช่องเดียวกันได้ | 3, 6, 12, 24, 48, ? |
| ก, ข, ค, ง, จ | ตัวเลือก | 96 |
| คำตอบ | ตัวอักษรของข้อที่ถูก | ข |
| วิธีทำ | วิธีทำเต็ม | … |
| วิธีลัด | วิธีลัด | … |
| เหตุผลตัวเลือกหลอก | เขียนแบบ `ก: เหตุผล \| ค: เหตุผล` | ก: นับเกินไป 1 พจน์ \| ค: … |
| เวลาเป้าหมาย_วินาที | ตัวเลขวินาที | 30 |
| ไฟล์รูป | ชื่อไฟล์ในโฟลเดอร์ figures | QR-N2A-0001.svg |
| ชุดข้อมูล | ใส่ชื่อเดียวกันถ้าหลายข้อใช้กราฟเดียวกัน ใส่ไฟล์รูปข้อเดียวก็พอ | DS-N4A-0003 |
| สลับตัวเลือกได้ | ใช่ / ไม่ (เว้นว่าง = ใช่ · N5 ไม่สลับเสมอ) | ใช่ |

ข้อควรรู้:
- **อนุกรม N1:** ใส่พจน์คั่นด้วย "จุลภาค + เว้นวรรค" เช่น `1,024, 1,280, ?` ตัวเลขหลักพันที่มีจุลภาคแต่ไม่มีเว้นวรรคจะถือเป็นตัวเลขเดียว
- **Excel แปลงค่าเอง:** Excel ชอบเปลี่ยน `1/4` เป็นวันที่ ให้ตั้งรูปแบบเซลล์เป็น "ข้อความ" ก่อนพิมพ์
- **CSV รุ่นเก่า:** ยังใช้ได้ (คอลัมน์ ส่วน, หัวข้อย่อย, เฉลยสั้น)
  - "เฉลยสั้น" แยกเป็นวิธีทำกับวิธีลัดด้วย ` | ลัด: `
  - ข้อที่ id ขึ้นต้นด้วย `NT-` จะไม่ถูกนำมาสุ่ม

### ตรวจหลังอัปโหลดทุกครั้ง

เปิด `ที่อยู่เว็บ/?check=1` จะเห็นสิ่งต่อไปนี้
- ไฟล์ที่เว็บกำลังใช้
- จำนวนโจทย์แยกตามหัวข้อและระดับดาว
- รายการข้อที่ข้อมูลไม่ครบ พร้อมเลขแถวหรือเลขข้อ ให้แก้ได้ตรงจุด

ถ้าหน้ายังเห็นโจทย์ชุดเก่า ให้รอ 1–2 นาทีแล้วรีเฟรช

ถ้าเปลี่ยน id ของข้อเดิม เว็บจะถือว่าเป็นข้อใหม่ ผู้เรียนจะได้เจอข้อนั้นอีกครั้ง

## 3. ใช้โดเมนของตัวเอง

ทำตามลำดับนี้ เพื่อกันคนอื่นแอบใช้โดเมนของคุณ

1. ใน GitHub ไปที่ **Settings → Pages → Custom domain** พิมพ์โดเมน แล้วกด **Save**
   - ตัวอย่างโดเมนย่อย: `fire.example.com`
   - ตัวอย่างโดเมนหลัก: `example.com`
   - GitHub จะสร้างไฟล์ `CNAME` ให้เอง
2. เข้าหน้าตั้งค่า DNS ของที่ที่ซื้อโดเมนไว้ แล้วเพิ่มระเบียนตามแบบที่ใช้
   - **โดเมนย่อย** (แนะนำ เช่น `fire.example.com`): เพิ่มระเบียน **CNAME** ชื่อ `fire` ค่าเป็น `ชื่อผู้ใช้.github.io`
   - **โดเมนหลัก** (`example.com`): เพิ่มระเบียน **A** ชื่อ `@` จำนวน 4 รายการ คือ `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153` และเพิ่ม CNAME ชื่อ `www` ค่าเป็น `ชื่อผู้ใช้.github.io`
3. รอให้ DNS ทำงาน ปกติไม่กี่นาที บางเจ้าอาจนานถึง 24 ชั่วโมง
4. กลับไปที่หน้า Pages แล้วติ๊ก **Enforce HTTPS**

เมื่อเสร็จแล้ว ลิงก์จะเป็น `https://fire.example.com/n1` ถึง `/n6` และใช้งานได้ทันทีโดยไม่ต้องแก้ไฟล์ใด

ข้อมูล DNS อ้างอิงจากคู่มือ GitHub Pages ณ ตอนจัดทำ ถ้าหน้า Settings ของ GitHub แสดงค่าต่างไป ให้ยึดตามหน้านั้น

## 4. สร้าง QR 6 อัน

ลิงก์ที่ต้องทำ QR (เปลี่ยน `โดเมน` เป็นที่อยู่จริง):

| หัวข้อ | ลิงก์ |
|---|---|
| N1 อนุกรม | `https://โดเมน/n1` |
| N2 ตารางและแผนภาพตัวเลข | `https://โดเมน/n2` |
| N3 ร้อยละ อัตราส่วน อัตราเร็ว | `https://โดเมน/n3` |
| N4 อ่านกราฟและตาราง | `https://โดเมน/n4` |
| N5 ข้อมูลเพียงพอหรือไม่ | `https://โดเมน/n5` |
| N6 ประมาณค่าและคิดเลขเร็ว | `https://โดเมน/n6` |

ถ้ายังไม่มีโดเมนของตัวเอง ลิงก์จะเป็น `https://ชื่อผู้ใช้.github.io/ชื่อ-repo/n1`

1. ใช้เว็บสร้าง QR ที่สร้างแบบ **static** (ลิงก์ฝังอยู่ใน QR โดยตรง) หลีกเลี่ยงแบบ "dynamic" ที่ต้องสมัครสมาชิก เพราะ QR อาจหยุดทำงานเมื่อหมดอายุ
2. เลือกระดับกู้ข้อผิดพลาด (Error correction) **M** หรือ **Q** แล้วดาวน์โหลดเป็น SVG หรือ PNG ความละเอียดสูง
3. วาง QR ในชีทขนาดอย่างน้อย 2 × 2 ซม. และเว้นขอบขาวรอบ QR
4. พิมพ์ชีทตัวอย่างหนึ่งแผ่น แล้วสแกนด้วยมือถือทั้ง iPhone และ Android ก่อนสั่งพิมพ์จริง

เคล็ดลับ: ทำ QR จากลิงก์สั้น `/n1` แทนลิงก์ยาว `?topic=N1` เพราะ QR จะเรียบง่ายกว่า สแกนติดง่ายกว่า และถ้าย้ายเว็บในอนาคต ก็แค่ตั้งโดเมนเดิมให้ชี้ไปที่ใหม่ ไม่ต้องพิมพ์ชีทใหม่
